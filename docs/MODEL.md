# 风险口径与证据

## 数据来源

来源是Perpl官方 `/v1/pub/context`、市场book和candles接口，以及独立API key的
wallet/positions/order-history。链上只读RPC使用Monad对应链端点，先核对chainId。
主网143、测试网10143；实例与抵押代币地址从对应context发现。

价格/数量按配置的小数位换算；Micros费率与资金费率除以1e6，bps为raw/100。
当前公开context支持的市场动态发现，不将主网市场ID用于测试网。

公共快照保留URL、抓取时间与原始响应SHA256；时间是UTC毫秒，界面本地显示。
独立演示前端不内置行情快照，运行视图加载同源API数据；读取失败时保持空值或明确标记旧观察。
每个图表的display/source rows都是当前选中市场；行内时间标识该观察。
预演JSON保存完整context和book，按保存的createdAt复算，不以当前行情覆盖旧证据。
原始响应哈希与导出快照规范JSON哈希分别保存；哈希帮助比较和复算，不独立证明API
真实性，也不是密码签名。已成交记录必须另核验链回执。

## 假设仓位

数量向下取最小数量单位；从做多卖盘/做空买盘逐档计算VWAP。
不足深度、市场暂停、超滑点、超杠杆、低于最小成交额和陈旧数据均阻断测试开仓。
前端按基础费率预演；提交时按实际Account.ft重算，并重新检查余额及空仓状态。

公式（独立孤立线性仓位，货币单位为抵押代币）：

- `notional = sum(price_i * matched_size_i)`
- `margin_budget = notional / requested_leverage`
- `entry_fee = notional * taker_fee_raw / 1e6`
- `funding_cost_estimate = notional * funding_rate_raw / 1e6 * side * hours*3600/interval`
- `gross_pnl = size * (stress_mark - entry_vwap) * side`
- `exit_fee = size * stress_mark * taker_fee_raw / 1e6`
- `net_pnl = gross_pnl - entry_fee - exit_fee - funding_cost_estimate`
- `maintenance_estimate = entry_notional * 100 / maintenance_margin_raw`
- `liquidation_estimate = max(0, entry + side*(maintenance - margin_budget + entry_fee + funding_cost)/size)`

side做多为+1、做空为-1。清算估算把开仓费计入预算消耗，采取保守假设；
不代表协议保证的清算价。资金费用假定最新费率恒定，按时间比例估算；
实际是离散结算，不能将此值宣传为已支付费用。费用/资金数据未知时PnL为null。

维持保证金的API字段是杠杆百分之一的编码，**不是 raw/10000**；
官方SDK采用入场名义金额/维持杠杆，并非冲击后的名义金额。
来源：[官方position.rs](https://docs.rs/perpl-sdk/0.2.7/src/perpl_sdk/state/position.rs.html)。

## 两方案对比

`/api/compare` 对两个独立假设仓位复用同一context、完整book、公开基础费率与
评估时刻。金额、杠杆、持有时间可不同；界面共用方向、冲击和滑点上限，避免混淆。
保存为 `comparison_` 记录，不用于发单，也不求和为投资组合或真实交易量。
压力图的净值是保证金预算+扣费后损益，含假设平仓费，与未平仓权益口径区分。
静态情景不模拟提前清算，因此穿过清算阈值后的数值不代表可实际实现的结果。
下载证据复算全部模型输出，包括未知值、风险原因与压力行；模型版本不匹配拒绝复算。

## 真实仓位

入场价保留Q16余数：多仓非零余数 `(ep-1+epr/65536)/price_scale`，
空仓 `(ep+epr/65536)/price_scale`。
仓位权益是协议抵押量+未实现价格PnL+估算累计资金PnL，不重复扣入场费。
未来尚未应用的资金事件、未知市场、陈旧快照均标为不完整。
仓位最近更新时刻不同于本次账户快照的观察时刻，不据旧开仓时间误报数据陈旧。
实际 REST 开放仓位可能返回 `at: {}`；官方 `BlockTxLogTimestamp` 的时间/区块字段均为可选。此时采用外层 `WalletPositions.at/sn` 核对观察新鲜度，仓位更新时间保持 null，不伪造为采集时间。若更新时间或区块有值，仍拒绝非法值、未来时间和超出快照的区块。2026-10-10 已通过一次实际非空测试仓位采集与回放；后续同一测试仓位的清算价已完成独立Decimal复算与官方持仓页面显示精度对照；随后两轮测试网多头完整开平仓均通过回执、费用、抵押返还与账户收支核对，其中一轮关联事前基线。详见 HISTORY_ACCEPTANCE.md；这些历史样本不代表所有仓位类型均已验收。

本模型未复刻账户合并、订单竞争、ADL、费用舍入和清算执行。
AUSD计价不保证兑美元价值；gas未纳入虚拟交易收益，代付交易gas不当作用户已付。
已有测试网多头完整开平仓费用核对，以及一份持仓清算价的独立复算与官方页面精度对照；空头、部分退出和真实清算执行仍未完成实际链端验收。

## 回执核验

### 本地开仓执行偏差

新增订单在提交前保存 `estimateEvidence` 的context、book、时间和哈希；执行核对先完整复算当前模型，核对市场、方向、数量与杠杆请求，再读取本地保存的API订单和回执。

按[官方Order类型](https://github.com/PerplFoundation/api-docs/blob/main/types.md#order)，`fs`是已成交数量，`fp`是缩放后的成交加权均价，`f`是抵押代币最小单位计价的总交易费（包含builder部分）。本页只支持开仓IOC，非零builder附加费事件当前保留为未支持证据，不猜测其拆分。

使用保存的transaction/receipt重新核对链、区块哈希、高度、交易成功、唯一请求和事件成交量/费用；不相信单独保存的`chainVerified`布尔值。API均价与事件加权价允许不足一个价格单位的取整差异。回执缺失或不一致，API观察另列且不填入已核对单元格。

- 同数量预估名义额 = 提交前VWAP × 已成交数量。
- 同数量预估交易费 = 同数量预估名义额 × 提交前费率。
- 不利价格差额成本 = 买入时+1、卖出时-1 × (回执VWAP − 提交前VWAP) × 已成交数量。
- 费用差额 = 事件核对费用 − 同数量预估费用。
- 费用价格变化分量 = (事件名义额 − 同数量预估名义额) × 提交前费率。
- 剩余费用差额 = 事件核对费用 − 事件名义额 × 提交前费率。

部分成交不把未成交数量计入费用。剩余费用差额可能含取整/费率/协议费用，不能直接归因为某个原因。零成交价格保持null，实际资金费用、平仓费用与已实现PnL未核验，保持null。

这是本地存档一致性核对，不重新访问链节点，不证明当前链最终性、节点来源或真实账户使用资格。合成样例单独分类，不进入订单账本。旧记录若缺少提交前快照，标记为证据不足。导出整包可用 `scripts/replay.mjs` 完整复算报告；哈希不是来源认证。

使用官方SDK0.2.7的事件ABI，保留许可证及修订。
核对chainId、成功状态、交易哈希/区块/交易所地址/日志位置；解码唯一的
OrderRequest账户、perpetualId、rq、方向、数量，并在其事件区间内核对
TakerOrderFilled的总数量与费用。不接受任意成功交易哈希作为成交证明。
未知ABI、不一致、历史分页不足500条未找到、缺少回执均不算通过。

测试使用明确标识的合成数据与编码事件检验数学和拒绝路径，不冒充真实链成交。

## 持仓与退出估算（position-exit-v1）

官方仓位定义：https://github.com/PerplFoundation/api-docs/blob/main/types.md#position 。仅接受开放仓位快照，不接受结算事件行。`fee` 为剩余数量携带的已收取入场费用（包含其builder份额），不是未来退出费。

- 当前权益 = 仓位抵押 + 未实现价格损益 + 已应用资金损益；不再扣留存入场费。
- 多头退出遍历bid、空头退出遍历ask。退出比例为1–100整数百分比，原始数量用BigInt向下取整。
- 预计退出净损益 = 可匹配数量的价格损益 + 分摊已应用资金损益 − 分摊入场费 − 盘口成交额×吃单费率。
- 分摊按可匹配数量/当前仓位数量，不按请求数量。部分退出保留剩余数量、未实现价格损益、资金损益和入场费；实际抵押释放与结算后权益保持null。
- 资金事件在当前上下文链头未到达应用区块时为未知；资金或入场费缺失时净损益保持null。维持保证金缺失时不将其转换为0。
- 市场、读取快照、盘口超过45秒/未来5秒或区块超出上下文链头，标记incomplete。价格、数量、金额拒绝不安全整数与非正价格。
- 实际账户使用Account.ft费用档位；合成案例用公开基础档。退出费不包含未知builder附加费用、gas、未来资金变化或订单竞争，不复刻协议逐笔整数舍入。
- `observed_position_exit_estimate` 只说明输入为账户/API观察，不证明发生退出；`synthetic_position_exit` 完全为本地案例。实际已实现损益与实际退出费始终为null。
- 导出保存完整仓位、context、book、时间、档位、来源分类、输入和结果哈希；`node scripts/replay.mjs /absolute/file.json` 检查全部结果及未知值。哈希不认证上游来源或防止整份文件被重新伪造。

## 风险观察（risk-watch-v1）

- 身份按网络、来源、账户、仓位和市场匹配；只接受开放仓位。实际与本地合成观察分别分类，不生成交易。
- 账户读取时刻、市场时刻须在45秒内且不超过未来5秒；对应区块须被上下文链头覆盖。仓位上次更新时间不当作当前读取时间，但不得超过当前快照时间/区块。陈旧、缺少资金或维持保证金、身份不符保持不完整。
- `bufferPct = (equity − maintenanceEstimate) / maintenanceEstimate × 100`；权益沿用上述仓位模型。低于/等于估算维持额为 `at_risk`，其余按每次观察保存的用户阈值判断 `caution` 或 `healthy`；这些状态不是协议清算证明。
- 仓位未出现在本次开放快照为 `not_observed`，不证明已平仓、释放保证金或结算。接口错误为 `read_error`；不沿用旧数值填充当前风险字段。
- 每网络一次刷新共用账户与市场输入；60秒最低间隔在外部读取前落盘，重复请求/重启返回旧观察，不创造新采样时刻。页面打开且勾选时才自动刷新。
- 阈值修改只影响下次观察，历史保留原阈值。相同状态不新增事件；不同的不完整原因仍保存在观察明细。最多30次观察与30条状态变化，最后一次可计算观察另保留，即使其状态为风险。
- 八阶段合成序列覆盖正常、临近阈值、估算维持额不足、未知资金、陈旧、读取失败、仓位未出现与恢复；不代表任何真实账户行为。
- 导出完整输入、计算时刻、每次阈值、报告和哈希，逐条完整复算。已读记录是本地界面状态，不是已送达通知或来源认证；不发送邮件。
